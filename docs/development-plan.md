# Remaining work

Ticket workflows, account/category/role administration, MFA, audit records, ranked
search, and explicit database provisioning are implemented.

Before the course demonstration:

- Run the [acceptance checks](test-and-demo-plan.md) with disposable data.
- Verify hosted HTTPS, proxy handling, login throttling, and restricted database grants.
- Complete a PostgreSQL backup/restore drill in a separate database.
- Record professor-requested changes in the [change log](change-log.md).

Use [requirements](requirements.md) to keep scope focused. Design mockups are
references, not additional feature requirements. Deployment checks are listed in
the [operations guide](azure-deployment.md#hosted-acceptance-and-backup-drill).
